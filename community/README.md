# 👥 Thèmes Communautaires Vérifiés

Ici vous trouverez les thèmes graphiques créés par la communauté KaïroOS et validés par l'équipe.

## ✨ Caractéristiques
- **Personnalisations créatives** : ambiances rétro, cyberpunk, néon, minimalistes, etc.
- **Sécurité garantie** : aucun script exécutable, uniquement des configurations de styles et assets graphiques.
- **Disponibles directement** dans le store de thèmes de KaïroOS.

## 🚀 Proposer un thème
Pour ajouter votre création ici :
1. Créez un dossier `community/{nom-de-votre-theme}/`.
2. Incluez votre `theme.json` et un fichier `preview.png` ou `preview.svg`.
3. Ouvrez une Pull Request sur ce dépôt.
