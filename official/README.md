# 🎨 Thèmes Officiels KaïroOS

Ici vous trouverez les thèmes visuels officiels conçus et validés par l'équipe KaïroOS.

## ✨ Caractéristiques
- **Styles optimisés** pour tous les formats d'écran et layouts (TV, desktop, handheld).
- **Palettes et polices calibrées** avec prévisualisation fidèle.
- **Installation et application instantanées** depuis l'onglet Thèmes de KaïroOS.

## 📂 Structure d'un thème
Chaque dossier contient :
- `theme.json` : configuration complète des couleurs, polices et disposition.
- `preview.svg` ou `preview.png` : image d'aperçu pour le sélecteur visuel.
